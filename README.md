# moon-ipset

A pure MoonBit IPv4/IPv6 address-set library for network allowlists, exclusions,
and minimal CIDR covers. Development in progress; no release or contest approval
is claimed yet.

The intended deliverable includes a reusable library, a JSON Lines CLI, runnable
examples, MoonBit tests, and an independent Python `ipaddress` differential suite.
See [the behavioral specification](docs/SPEC.md).

License: MIT. Dependencies and reference sources will be recorded in
`docs/PROVENANCE.md` before release.
