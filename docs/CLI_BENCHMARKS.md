# 文件 CLI 端到端基准

本表比较提交 [`e462259`](https://github.com/tc-adventureking/moon-ipset/commit/e462259) 中的 JSON 文件传输与 0.2.1 的 `FileReadResult` 正式实现。已从该提交重新构建并核对基线产物摘要。测量使用冻结的编译产物，每次核对完整输出与退出码，没有把隔离诊断副本的结果当作正式收益。

逐次样本、输入和产物指纹见 [cli-e2e.json](../bench/results/cli-e2e.json)。

2026-10-26，Ubuntu WSL 2、Intel Core i9-14900HX、Node.js 24.22.1。每例预热一次，再交错运行两版各五次，逐轮交换先后顺序。时间为墙钟中位数，括号内为最小值到最大值；RSS 为五次峰值的中位数。

| 每份文件行数 | 操作 | 原版 ms（范围） | 正式实现 ms（范围） | 中位时间变化 | RSS MiB：原版 → 正式 |
| ---: | --- | ---: | ---: | ---: | ---: |
| 10,000 | normalize | 546.5 (346.8–571.8) | 388.6 (368.6–480.4) | -28.9% | 72.2 → 72.0 |
| 10,000 | diff | 421.6 (359.1–817.0) | 457.4 (356.5–618.4) | +8.5% | 76.5 → 75.0 |
| 100,000 | normalize | 451.3 (409.5–920.3) | 620.8 (420.9–821.9) | +37.6% | 145.4 → 116.0 |
| 100,000 | diff | 718.6 (508.9–806.7) | 594.5 (488.7–716.0) | -17.3% | 200.3 → 161.5 |
| 1,000,000 | normalize | 1728.6 (1665.6–1833.1) | 1625.7 (1543.5–1829.7) | -6.0% | 447.9 → 381.0 |
| 1,000,000 | diff | 3554.9 (3236.1–3644.5) | 2859.2 (2763.6–3234.9) | -19.6% | 570.9 → 535.9 |

一百万行样本的两个操作都有中位耗时和内存改善，但 100,000 行 normalize、10,000 行 diff 的中位耗时更高。若干五次范围明显重叠，不能据此承诺所有规模都更快，也不把波动消除后的性能当作已测事实。

## 输入与计时范围

- 固定种子 `20261026`，每份输入由 2,048 条乱序双栈记录重复至指定行数，包含裸地址、CIDR、大小写和默认模式允许的主机位。两份清单部分重叠。
- normalize 读一份文件，diff 读两份。因此一百万行 diff 实际处理两百万行；一百万行单文件约 16.27 MB。
- 最终集合规模保持有界，JSON 输出分别为 38,860、38,419 字节。本表不代表一百万条互不相交网段或大量输出的性能。
- 每次启动独立 Node 进程；计时包含启动、读取、解析、集合运算、序列化、stdout 管道传输和退出，不含生成输入、构建和 Python 参考核对。
- 每次使用 Python `ipaddress` 与独立地址点集验证结果。normalize 退出 0，有变化的 diff 退出 1。
- Linux `/usr/bin/time -q -f %M` 单独测量每次进程的最大 RSS；不是累计子进程最大值。输入位于 WSL 的 Windows 挂载文件系统，没有固定 CPU 频率。

原版编译产物 SHA256：`10488f57d394d7949c6121d0ce591f52c8e8c10696b3c8ea245008a38c07eddf`。正式实现：`733afae492b99fe4c204b293e6911a534db4a00093a5d7defb803208d6c094e3`。其他分布的核心运算测量见 [BENCHMARKS.md](BENCHMARKS.md)。

## 复现

用已解压的便携 CLI 测量单个版本，避免将自动构建入口的耗时计入：

```bash
python3 scripts/benchmark_cli.py \
  --command "node /path/to/unpacked/ipset.mjs" \
  --runs 5 --warmup 1 --timeout 120 \
  --fixtures work/cli-benchmark-inputs \
  --output work/cli-benchmark.json
```

报告包含逐次时间、范围、标准差、每进程 RSS、输入与编译产物指纹。可用 `--sizes 1000000 --operations normalize --runs 1 --warmup 0` 先估计本机成本。跨版本比较应交替运行，保留全部样本；此脚本不设置性能通过阈值。
