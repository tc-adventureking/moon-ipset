# 第二轮源码审查结论

按已约定行为逐项推导，**未发现有可靠反例的高或中严重度缺陷**。只发现一项低严重度的不一致。

## 问题（低）：IPv4 尾段的错误载荷不一致

- **位置**：`parse_v6_groups` 调用 `parse_v4_word(group)`。
- **输入**：`::ffff:1.2.3.256`，或 `1:2:3:4:5:6:1.2.3`。
- **预期**：同一函数的其他分支都抛 `InvalidAddress(original)`，这里应得到 `InvalidAddress("::ffff:1.2.3.256")`。
- **实际**：得到 `InvalidAddress("1.2.3.256")`。错误变体正确，集合结果不受影响。只有 CLI 或测试比较错误文本时才会看到差异。
- **最小修复**：给 `parse_v4_word` 增加 `original` 参数，所有 raise 都使用它。`Address::parse` 的 IPv4 分支传入 `text`。
- **另**：`Cidr::new` 用规范化后的地址拼接错误文本，例如 `::0001/129` 报 `"::1/129"`。`Cidr::parse` 的地址错误只带地址部分。CIDR 错误载荷的契约：Not specified，因此未计为缺陷。

## 已检查的关键不变量

1. **解析**
   - IPv4：恰好 4 段，每段 1–3 位，无前导零，≤255。
   - IPv6：每组 1–4 位 hex；只允许一个 `::`，且至少补 1 组。
   - `:::`、`1:::2` 和首尾单冒号会被空组规则拒绝。
   - IPv4 只允许出现在最后一段。
   - 45 字符上限等于最长的合法混写长度。
   - 空白、`%`、`[]` 和端口都会被拒绝。
2. **比较**：先比较地址族（V4<V6），再按 a→d 做无符号比较，与 Eq 一致。
3. **next/previous**：V4 只改动 d；V6 逐字进位或借位；最大值和 0 返回 None，不跨族。
4. **mask/block_end**：V4 偏移 96 位后 a/b/c 保持为 0；prefix 为 0、32、128 时边界正确。
5. **append_canonical 的前提**：各调用方的输出都满足 lo 不递减，跨族和最大地址都不会合并。调用方包括 from_ranges（排序后）、union（按 lo 归并）、intersection 和 difference（单调输出）。
6. **difference**
   - j 单调推进。
   - 首个排除区间满足 hi≥source.lo；规范集非相邻，所以后续排除区间满足 lo>cursor。因此不会漏发或重叠。
   - hi≥source.hi 时保留 j 是正确的。
   - hi<source.hi 保证 next() 存在。
7. **intersection/overlaps**：跨族时推进 V4 一侧。
8. **cidrs**
   - 起点按尾零对齐。
   - prefix 最多增加到 width，此时 block_end=cursor≤hi，循环必然终止。
   - 每步取最大对齐块，即得到最小覆盖。
9. **别名**：from_ranges 和 intervals 都复制数组，各运算都新建数组。
10. **to_string**：只压缩长度≥2 的最长零串，平局时取第一个。

## 建议新增的回归（3 条）

1. **解析边界**
   - 应接受：`1:2:3:4:5:6:7::`、`::2:3:4:5:6:7:8`，以及 45 字符的 `0000:0000:0000:0000:0000:ffff:255.255.255.255`。
   - 应拒绝：`1:2:3:4:5:6::1.2.3.4`、`::1.2.3.4:5`、`1.2.3.4::`、`::ffff:01.2.3.4`、`1.2.3.4/024`。
   - 同时断言错误载荷。
2. **字边界**
   - 区间 `[::ffff:ffff, ::1:0:0]` 的 cidrs 应为 `::ffff:ffff/128` 和 `::1:0:0/128`。
   - 区间 `[0:0:0:1::, 0:0:0:1:ffff:ffff:ffff:ffff]` 应为 `0:0:0:1::/64`，这一条同时检验最长零串的选择。
   - `0.0.0.0/0` 和 `::/0` 应能往返。
3. **跨族与极值**
   - `{255.255.255.255/32} ∪ {::/128}` 应保持为两个区间。
   - `{0.0.0.0/0, ::/0}` 分别减去各族的 0 地址和最大地址。
   - `{1.2.3.4/32}` 不应包含 `::ffff:1.2.3.4`。
