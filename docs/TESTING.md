# 验证范围

0.3.0 使用 MoonBit 0.1.20261023 / moonc 0.10.17、Node.js 24.22.1，在 Ubuntu WSL 2 验证。公开检查入口为：

```bash
bash scripts/verify.sh
```

在源码仓库根目录执行，需要 MoonBit、Node.js 24 LTS、`unzip` 与 C 工具链，无需 Python。入口检查格式、零警告编译、四目标测试、公共 API 文件、消费示例及文件 CLI；GitHub Actions 使用同一入口，工具链 stable 可能随时间更新。

仅验证安装包可运行 `bash scripts/verify-package.sh`：调用官方 `moon package`，检查源码和许可文件与仓库一致、无 Python 或开发目录、包内文档链接有效；再把库解包到独立临时目录，使用同一组消费者场景执行四目标测试。消费者只能访问解包后的库，不能回退到本仓库源码。此检查验证本地生成的 ZIP，不等同于从 Mooncakes 下载已发布版本。

2026-10-31 在上述工具链完成安装包检查：4 个消费者测试在四目标各通过一次，共 16 次执行。缺失许可证、许可证内容被改动、混入 Python 文件、失效文档链接四类反例均被拒绝；反例构造工具仅保留本地。默认临时目录为 `/tmp`，自定义 `TMPDIR` 时须位于源码仓库外。

## 测试覆盖

- 地址：文本/字节/大整数往返、IPv6 scope、特殊地址分类与例外、mapped/6to4/Teredo、格式、溢出及 Map 键。
- 网络：严格默认值、点分掩码/反掩码、所有前缀长度、2^128 地址计数、负索引、子网/超网、包含/重叠、排除与归并。
- 接口：主机与网络分离、scope、配置格式、算术和混合输入；惰性迭代测试只取有限项，覆盖 /31、/32、/127、/128。
- 旧功能：集合代数、最小 CIDR 覆盖、CLI JSONL/文件协议、错误恢复和退出码。公开 MoonBit 测试保留有限空间集合检查。

## 字节转换基准

源码仓库运行 `moon run bench --target native --release -- --packed`，加 `--smoke` 可缩小输入。使用固定种子的 IPv4/IPv6 数据，包含全零与全 1；计时外生成输入和校验往返，计时内转换整批并保留结果。输出 JSONL，单位为每批微秒，包含结果数组分配。

2026-10-31 在上述 WSL 工具链比较 `bf7f8c6` 的库实现与直接字节转换实现：每批 256 个地址，5 轮交替运行，每轮 7 次采样。下表耗时是各轮中位数的中位数，倍率是逐轮配对倍率的中位数。

| 操作 | 原实现 μs/批 | 直接转换 μs/批 | 配对倍率 |
| --- | ---: | ---: | ---: |
| IPv4 `from_bytes` | 121.53 | 11.79 | 10.72× |
| IPv6 `from_bytes` | 134.54 | 12.83 | 10.69× |
| IPv4 `to_bytes` | 51.79 | 10.58 | 4.89× |
| IPv6 `to_bytes` | 79.31 | 18.79 | 4.20× |

这是本机 native 微基准，不能推导整个库或其他后端的提速。字节回归覆盖 10,240 个逐位置数值/背景组合、1,024 个固定随机输入，以及长度、前导零、地址族和 scope 边界；通过独立 BigInt 路径检查数值，避免仅靠往返掩盖相同的编码/解码错误。
