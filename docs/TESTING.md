## 复现与限制

在有 MoonBit、Node.js、Python 和 C 工具链的 Linux／WSL 环境执行：

```bash
bash scripts/verify.sh
```

结果写入 `work/verification/`；任一步失败都会返回非零退出码。GitHub Actions 执行同一入口，并上传报告，见仓库的 [Actions](https://github.com/tc-adventureking/moon-ipset/actions)。

CI 安装运行时的官方 stable 工具链，并记录精确版本；stable 将来可能变化。本页记录的是上述版本与日期的实测，不承诺未来版本无变化。有限空间穷举和固定随机测试不是全部 IPv4/IPv6 输入的形式证明；尚未进行性能基准、长期负载或实际防火墙集成验证。CLI 当前为读取到 EOF 后处理的批处理适配器。
